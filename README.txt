مطعم السيد عبيد - ملفات الموقع

طريقة النشر المجاني عبر GitHub Pages:
1. افتح المستودع الذي أنشأته على GitHub.
2. اضغط Add file ثم Upload files.
3. ارفع index.html و style.css و script.js.
4. اضغط Commit changes.
5. افتح Settings ثم Pages.
6. ضمن Build and deployment اختر Deploy from a branch.
7. اختر Branch: main و Folder: / (root)، ثم Save.
8. انتظر قليلاً وافتح رابط الموقع الذي يظهر في صفحة Pages.

مهم: الأسعار مأخوذة من المعلومات السابقة، فتأكد منها قبل النشر. هذا موقع ثابت؛ تعديل الأسعار يكون بتعديل index.html ثم رفعه مجدداً. لوحة إدارة آمنة ومزامنة للأسعار تحتاج إلى خدمة خلفية، ولا ينبغي وضع كلمة مرور سرية داخل ملفات الموقع.
